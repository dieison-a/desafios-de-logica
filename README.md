# Oficina de Cálculos

Painel de cálculos cotidianos com comissão progressiva, saque em cédulas, estoque, idade aproximada e diagonal de matriz.

## Como executar

Abra `index.html` em um navegador moderno. O projeto funciona localmente, sem instalação ou conexão externa.

## Nota sobre a versão pública

Este exercício acadêmico foi desenvolvido individualmente antes desta versão. A versão pública foi redesenhada e refatorada em 2026 com assistência de IA. Não inclui enunciados, boilerplate ou ativos de terceiros; os dados apresentados são fictícios.
